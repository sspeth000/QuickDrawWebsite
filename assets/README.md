# Assets

- `original/`: small PNG images extracted from the supplied APK's drawable resources. These are original binary assets, not browser redraws.
- `quick-draw-mark.svg`: a newly recreated vector mark used by the browser UI; it is not represented as an original APK asset.

The full APK contains many additional Android drawables, layouts, and language split resources. The repository is not yet a complete mirror of every binary resource from the XAPK.
