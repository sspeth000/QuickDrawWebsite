# Quick Draw — Draw & Paint (Web Edition)

A browser-based recreation of the original Android app's core drawing experience, rebuilt from the supplied decompiled source as a static site for GitHub Pages.

## Features
- The original 44-color paint palette and matching background-color palette
- Brush and eraser modes with the original size choices
- Drawing sheet with mouse, touch, and stylus support
- New drawing confirmation, open an image, save as PNG, and share where supported
- Undo and redo, plus responsive layout for desktop and mobile
- No build step or external dependencies

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

Expected site URL: https://sspeth000.github.io/QuickDrawWebsite/

This is a web recreation, not an executable conversion of the Android APK.
