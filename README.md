# Quick Draw — Draw & Paint (Web Edition)

A browser-based drawing app that works with GitHub Pages. This is a clean-room web recreation of drawing functionality, not an executable conversion of an Android APK/XAPK.

## Features
- Pen, marker, eraser, line, rectangle, and ellipse tools
- Color picker and preset swatches
- Adjustable brush size
- Undo/redo (up to 30 states)
- Save artwork as a PNG
- Responsive layout with mouse, stylus, and touch support
- No build step or external dependencies

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait for the deployment to finish. GitHub will show the site URL in Pages settings.

Expected site URL after Pages is enabled: https://sspeth000.github.io/QuickDrawWebsite/
